# Test inventory

This inventory has one entry per test module or standalone FreeCAD acceptance script. Each entry states its primary goal and the reason the coverage is useful. Update it with every test addition, removal, rename, or consolidation; during review, compare similar entries and remove tests that no longer exercise a distinct contract.

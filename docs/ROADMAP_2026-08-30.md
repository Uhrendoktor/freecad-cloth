# Cloth Workbench Roadmap and Research — 2026-08-30

## 1. Planning process

This roadmap was reworked after auditing every open pull request and issue before starting new implementation. The project is treated as two coordinated FreeCAD workbenches plus a shared document/IR layer:

1. **Pattern Workbench** — native Sketcher authoring plus garment-specific semantic tools.
2. **Sewing Workbench** — semantic seam creation/editing and sewing validation.
3. **Simulation Workbench** — derived mesh, fabric/material properties, avatar collision, pins and deterministic drape.
4. **Shared architecture** — PatternPiece semantics, semantic edge/seam references, PatternIR, dependency invalidation, export.

The roadmap deliberately does not attempt to clone every CLO/Marvelous Designer feature. The acceptance target is a coherent open-source CAD-native garment workflow.

## 2. CLO/Marvelous Designer behavior distilled

CLO's current 2D tool model combines pattern construction, curve editing, point insertion/splitting, seam allowance, notches, grain/reference markings, pleats, grading, pattern organization, and explicit sewing tools. Its sewing model includes segment-to-segment, free sewing, M:N segment sewing, and M:N free sewing, plus sewing-length checking. Its property editor exposes pattern, sewing, fabric, avatar and simulation properties.

CLO also treats **particle distance** as a first-class simulation-quality control: roughly 20 mm is a working resolution while values around 5 mm or lower are used for final quality. Hi/low-resolution garment presets also combine particle distance, collision thickness, avatar skin offset, and simulation quality. This maps naturally to FreeCAD as persistent mesh/simulation presets rather than a hidden solver constant.

Marvelous Designer is useful as a parity reference for the same 2D-pattern → sewing → avatar-drape workflow. We should borrow the workflow concepts, not proprietary implementation details or file formats.

## 3. Feature matrix

### Pattern Workbench

**Primary toolbar**

- New Pattern Piece
- Create/Edit Sketch
- Line / Arc / BSpline / Bezier (delegated to Sketcher where possible)
- Add Point / Split Geometry
- Coincident / Horizontal / Vertical / Tangent / dimensional constraints (native Sketcher)
- Seam Allowance
- Notch
- Grainline
- Internal Mark / Construction Geometry
- Mirror / Transform
- Pattern Annotation
- Pattern Validation
- 2D View / Fit All

**Task panel**

- Piece identity and labels
- seam allowance width and join policy
- grainline angle/reference
- derived validation state
- linked Sketcher object and geometry authority
- material/fabric link
- simulation resolution preset

**Interaction**

The PatternPiece is a semantic container. Its `Sketch` link points to the editable native `Sketcher::SketchObject`. The Sketcher object is the geometric source; PatternIR translates it into solver-neutral boundaries. Derived outlines, seam allowance and simulation meshes are never allowed to silently become authoritative.

### Sewing Workbench

**Primary toolbar**

- Segment Sewing
- Free Sewing
- M:N Segment Sewing
- M:N Free Sewing
- Reverse B
- Alignment: Endpoints / Uniform
- Stitch Group
- Seam Type: Plain / Dart / Gather / Pleat / Hem / Fold / Closure
- Check Sewing Length
- Validate Seams
- Show/Hide Seam References
- Delete/Edit Seam

**Task panel**

- Piece A / semantic edge A / normalized range
- Piece B / semantic edge B / normalized range
- reverse/alignment controls
- length delta and tolerance
- invalid/missing/changed reference diagnostics

Seams store stable semantic IDs plus signatures. Raw Sketcher insertion indices are accepted only at an adapter boundary and are resolved immediately.

### Simulation Workbench

**Primary toolbar**

- Select Avatar / Humanoid
- Arrange Pieces
- Pin / Unpin
- Simulate / Pause / Reset
- Working Quality
- Final Quality
- Fabric Preset
- Collision Preset
- Simulation Properties
- Fit / Rebuild Derived Mesh
- Validate Simulation Inputs
- Export Result

**Properties**

- particle distance / mesh resolution
- fabric density, stretch/compression compliance, bending and damping
- timestep, solver iterations and gravity
- collision thickness and deflection
- avatar skin offset
- pins and seam selection
- simulation status, invalidation reason, last rebuild time

Quality presets must change deterministic derived mesh resolution and collision settings. They must persist in the document and be visible in the property editor.

## 4. Existing FreeCAD tooling to reuse

- **Sketcher** for geometry, constraints, editing, solver state and native geometry storage.
- **Part/OCC** for wires, faces, offsets, geometric validation and curve topology.
- **Mesh** for display/derived simulation meshes.
- **Draft** only where its construction/annotation utilities complement native Sketcher.
- **PropertyLink / document dependency graph** for PatternPiece→Sketch and downstream invalidation.
- **Expressions** for dimensional parametric relationships where appropriate.
- **FreeCAD GUI workbench/task panels** for commands and contextual properties.

A custom 2D canvas is not the default authoring system. The existing PatternDrafting module becomes a compatibility/migration utility until the native toolbar covers the required garment-specific actions.

## 5. Milestones

### M0 — architecture and backlog hygiene

- audit/merge/close stale PRs
- document research and acceptance contracts
- establish `AGENT_STATUS.md`

### M1 — native Pattern authority

- Sketcher-linked PatternPiece
- stable semantic edge IDs
- PatternIR line/arc/BSpline/Bezier adapter
- save/reload and dimensional edit propagation

### M2 — sewing completeness

- curved edges
- M:N correspondences
- semantic range references
- length checking
- invalidation and repair UX

### M3 — simulation completeness

- authored PatternPiece/Sketch → PatternIR → derived mesh path
- working/final resolution presets
- fabric/collision presets
- humanoid collision and arrangement
- deterministic reset/re-simulate

### M4 — acceptance

- 3+ real Sketcher-backed pieces
- at least one curved seam
- save/reload
- edit source geometry
- observe seam/mesh/simulation invalidation
- re-simulate in real FreeCAD under Xvfb
- export and validate round-trip metadata

### M5 — packaging/release

- clean install in FreeCAD Addon Manager-compatible layout
- icons/resources
- documentation/tutorial fixture
- no stale duplicate architecture branches

## 6. Definition of done

The project is not considered a finished FreeCAD workbench until a user can start from a new document, create multiple native Sketcher-backed garment pieces, constrain/edit them parametrically, mark seam allowances/notches/grainlines, sew arbitrary/curved correspondences, assign fabric and simulation quality, arrange them on a humanoid collision model, simulate, edit the source sketch and see derived invalidation/rebuild, save/reload the document, and export a deterministic production representation.

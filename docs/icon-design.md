# Cloth workbench icons

The three workbench icons use established, recognizable symbols rather than bespoke abstract artwork:

- **Pattern:** Material Design Icons `ruler-square-compass`, a drafting/measuring symbol.
- **Sewing:** Material Design Icons `needle`, directly identifying sewing work.
- **Simulation:** Material Design Icons `human`, identifying the fitting/simulation target.

The source SVG paths are from the Material Design Icons repository and are redistributed here as local FreeCAD assets. Source files are available at:

- https://github.com/Templarian/MaterialDesign/blob/master/svg/ruler-square-compass.svg
- https://github.com/Templarian/MaterialDesign/blob/master/svg/needle.svg
- https://github.com/Templarian/MaterialDesign/blob/master/svg/human.svg

Material Design Icons is distributed under the Apache License 2.0. The original path geometry is retained; only the SVG wrapper/viewBox is kept minimal for FreeCAD. The icons intentionally avoid invented visual metaphors and remain recognizable at compact workbench-selector sizes.

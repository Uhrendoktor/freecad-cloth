# Roadmap

The canonical roadmap is [the documentation roadmap](docs/developers/ROADMAP.md).

This root file exists only for links and tools that conventionally expect `ROADMAP.md`. It is not a second roadmap and must not contain current-status claims, milestone copies, experiment logs, or historical run results.

For current repository state, use `AGENT_STATUS.md` and `TOOL_STATE.md`. For architecture and module ownership, use `docs/developers/ARCHITECTURE.md` and `docs/developers/PROJECT_STRUCTURE.md`.
